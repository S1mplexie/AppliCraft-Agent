## 课程结构

**结构说明**：6 门必修 + 5 门选修；小组项目在春季学期，个人项目 / 实习在夏季学期

**核心课程 / 必修**

- Python Programming
- Mathematics for Machine Learning
- Software Engineering Group Project
- Individual Project or Internship

**选修课程 / 方向**

- Reinforcement Learning
- Natural Language Processing
- Computer Vision
- Deep Learning
- Computational Optimisation
- Statistical Information Theory
- Generative AI

**Track / 专攻方向**

官网未分设 track

## 项目特色与就业

**项目特色**

- 官网：aimed at graduates of disciplines with a large mathematics component, other than computer science。
- 官网：intensive training in programming and AI with a wide choice of elective modules, a group project and a large individual project。
- 官网提到 personal project 可改为企业 AI 实习（internship）。

**就业去向（仅官网明确表述）**

- 官网列举毕业生进入 DeepMind、Facebook、Google、Twitter 等公司 AI 部门，也有毕业生继续读博或创业

## 文书参考要点（PS / SOP）

- 数学背景是该项目入口（数学 / 物理 / 工程 / 数量经济），文书应把数学课程与机器学习动机连起来，而非强调已有 CS 学历。
- 官网强调 Python 强化训练与小组 / 个人项目，可写你从零上手编程或跨团队合作的真实经历。
- 若有企业实习意向，可呼应官网 internship 替代个人项目的安排，但不要写成已获得名额。

> 以上要点依据项目官网原文提炼，供撰写 why-this-programme / 职业规划段落时参考；不得直接照抄为个人经历，也不得把官网表述当作已核实的项目事实写入硬指标。
