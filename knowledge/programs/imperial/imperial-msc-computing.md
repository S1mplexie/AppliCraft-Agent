## 课程结构

**结构说明**：秋季学期打基础，春季学期深化与分流，夏季学期完成大型软件项目与个人项目（论文 + 口头答辩）

**核心课程 / 必修**

- Principles and Practice of Programming
- Computer Systems
- Software Systems Engineering

**选修课程 / 方向**

- Databases
- Computer Vision
- Algorithms
- Quantum Computing
- AI Ventures
- Network and Web Security
- Introduction to Machine Learning

**Track / 专攻方向**

官网未分设 track

## 项目特色与就业

**项目特色**

- 官网：面向非计算机本科的 conversion 课程， Intensive training in computer science。
- 官网：A major focus is developing a large software project，并以 extended individual project 收尾。
- Department of Computing 在研究评估中位居英国前列，设有 Dyson Robotics Lab、Data Science Institute 等中心。

**就业去向（仅官网明确表述）**

- 官网表述毕业生进入 Computing 相关行业，另有不少毕业生继续攻读 PhD
