## 课程结构

**结构说明**：统计 + 计算机交叉的 professional entry program；四个 specialisation stream；最后一年 capstone

**核心课程 / 必修**

- 统计建模与推断
- 机器学习与数据挖掘
- 数据库系统
- 计算统计
- Major data science project / capstone

**选修课程 / 方向**

- Machine Learning
- Advanced Data Mining
- Database Systems
- Computational Statistics
- Science Communication / Internship

**Track / 专攻方向**

- Foundational
- Statistical
- Computational
- Computational and Statistical

## 项目特色与就业

**项目特色**

- 官网：professional entry program，combines statistics and computer science in a single coordinated program。
- 官网：四个 specialisation streams（foundational / statistical / computational / computational and statistical）。
- 官网：capstone subject 用公开或私有数据解决真实问题，并以 client-ready format 展示。

**就业去向（仅官网明确表述）**

- 官网指向 data analytics 职业，培养管理大型复杂数据集的分析与技术能力

## 文书参考要点（PS / SOP）

- 官网强调「不限本科 + 先修补齐」的灵活入口，转背景申请者应写清如何完成编程 / 微积分 / 线代先修。
- 四个 stream 中明确选择哪一个，并用过往统计建模或编程项目支撑，而非泛写「喜欢数据」。
- 呼应官网 capstone 的 client-ready presentation 要求，写你向非技术受众解释分析结果的经历。

> 以上要点依据项目官网原文提炼，供撰写 why-this-programme / 职业规划段落时参考；不得直接照抄为个人经历，也不得把官网表述当作已核实的项目事实写入硬指标。
