## 课程结构

**结构说明**：3 门 Data Science 核心 + 2 门 Computing professional core + 3 门 specialist elective + 1 门 capstone / research project + 选修或基础课

**核心课程 / 必修**

- Data Science core units
- Computing professional core units
- Capstone or research project

**选修课程 / 方向**

- Data Engineering
- Machine Learning

**Track / 专攻方向**

- Data Engineering
- Machine Learning

## 项目特色与就业

**项目特色**

- 官网：为具备数学或定量背景的专业人士设计，用数据科学支撑战略决策。
- 官网：悉尼大学计算机科学与信息系统 QS 2025 全澳第 1、全球第 36。
- 官网：ACS 条件性临时专业级别认证至 2026 年底，2027 复审结果待公布。

**就业去向（仅官网明确表述）**

- 官网列出 analytics consultant、business analyst、data engineer、machine learning engineer、statistician 等岗位

## 文书参考要点（PS / SOP）

- 与计算机硕士不同，本项目明确要求相关背景 + 编程 / 统计，文书要先证明背景匹配，再谈职业目标。
