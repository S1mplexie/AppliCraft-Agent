## 课程结构

**结构说明**：官网明确『required to read and pass five core courses and five elective courses (total: 40 units)』。AY2027/28 的确切 core/elective 划分与课程清单 待核实（官网 Course List 折叠区本次未展开）；下列 core 名称来自官方 AY2022 版 module list，electives 名称来自同一官方清单与数学系 AY2025/26 官方课程表，均已标注来源

**核心课程 / 必修**

- DSA5101 Introduction to Big Data for Industry（官方 AY2022 版 core 清单）
- DSA5103 Optimization Algorithms for Data Modelling（官方 AY2022 版 core 清单）
- DSA5104 Principles of Data Management and Retrieval（官方 AY2022 版 core 清单）
- DSA5105 Principles of Machine Learning（官方 AY2022 版 core 清单）
- DSA5201 DSML Industry Consulting and Applications Project（官方 AY2022 版 core 清单）

**选修课程 / 方向**

- DSA5202 Advanced Topics in Machine Learning
- DSA5204 Deep Learning and Applications
- DSA5206 Advanced Topics in Data Science
- DSA5102 Foundations of Machine Learning（数学系 AY2025/26 官方课程表）
- CS5228 Knowledge Discovery and Data Mining（官方 AY2022 版选修清单）
- ST5201 Statistical Foundations of Data Science（官方 AY2022 版选修清单）

- 呼应官网『an interdisciplinary graduate degree programme aimed at developing future leaders in data science and artificial intelligence』：文书须显式呈现数学、统计与计算机科学的跨学科整合能力。
- 官网『The curriculum encompasses fundamental disciplines such as computer science, mathematics and statistics, along with specialised areas like machine learning and artificial intelligence』：按基础学科 + ML/AI 专长两层组织学术准备。
