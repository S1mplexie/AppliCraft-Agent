## 课程结构

**结构说明**：核心 CS（系统与理论）+ 大量选修 + 论文；约一半授课学分来自核心计算机科学

**核心课程 / 必修**

- Computer Systems 基础与系统类核心课
- Algorithms
- Programming Languages
- Cryptography
- Quantum Informatics

**选修课程 / 方向**

- Parallel and Distributed Systems
- Security and Privacy
- Theoretical Computer Science

**Track / 专攻方向**

官网未分设 track

**项目特色**
